# 나를 소개하는 한 페이지

정적 HTML, CSS, JavaScript만으로 만든 개인정보 비노출형 개인 소개 페이지입니다.

## 실행과 공개

`index.html`을 브라우저에서 열면 됩니다. 배포 시에는 GitHub Pages, Netlify, Cloudflare Pages처럼 로그인 없이 정적 페이지를 열 수 있는 주소를 제출하세요. 이 저장소와 배포 주소는 시크릿 창에서 접근 가능한지 제출 전에 직접 확인해야 합니다.

## README를 반영한 공개 내용

- 한 문장 소개: 배움을 실전에 적용하고, 신뢰로 관계를 다져 가는 신중한 실천가
- 관심사: 음악·악기 연주, 여행, IT 인프라·보안, 프라모델 조립·목공
- 협업 기준: 맡은 일을 제때 마치고, 모르는 것은 묻고 아는 것은 나누기

README의 계획과 관심사를 바탕으로 문장을 채웠습니다. 실제로 하지 않은 경험처럼 보일 수 있는 표현은 넣지 않았습니다. 공개 범위는 배포 전에 본인의 선택과 다시 비교하세요.

현재 초안에는 실명, 연락처, 상세 위치, 학교·기관 식별 정보, 개인 계정, 인증 정보가 들어 있지 않습니다.

## 점검 항목

- 첫 화면에 소개·활동·근거가 함께 보이도록 구성
- 1366×768 및 1920×1080에서 가로 넘침 여부 확인
- 링크, Tab 이동, 제목 단계, 텍스트 대비, 콘솔 오류 점검
- 3개의 수정 전·후 기록, 마우스·키보드 상호작용, 움직임 줄이기 제어 포함
