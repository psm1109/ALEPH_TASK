# T01 과제 안내 1~5 검토

ALEPH Studio 가운데 과제 1과 과제 안내 1~5를 직접 읽고 대조했습니다.

## 반영한 보완

- C10~12: 긴 상세 본문 때문에 첫 화면에서 결과와 근거 링크가 아래로 밀렸습니다. 카드에 결과 요약을 두고 상황·행동·결과 원문을 details로 접어 근거 링크를 먼저 볼 수 있게 했습니다. 두 해상도의 실제 측정은 아직 필요합니다.
- C21: 학습 모달 트리거가 링크여서 Space가 페이지 스크롤로 동작했습니다. button으로 변경해 Enter와 Space의 기본 활성화를 지원합니다.
- C14: 모달에 Tab 초점 제한이 없어 배경 링크로 초점이 빠질 수 있었습니다. 배경 main/footer에 inert를 적용하고 첫/마지막 버튼 사이 초점을 순환시켰습니다. 닫으면 원래 버튼으로 돌아옵니다.

## 기준별 상태

- C01: 결과물과 소스 URL의 새 시크릿 창 접근 검증 필요. 제출 소스는 브랜치 주소가 아닌 full commit 포함 HTTPS 고정 URL이어야 합니다.
- C03~05: 대상·목적 문장과 공개/비공개 각 3개 있음.
- C06~09: 세 항목 모두 상황·행동·결과와 연결된 근거 있음. 첫 카드의 학습 사진은 장애 해결 자체의 증명과 구분해야 합니다. 안내는 관찰 가능한 결과 문장도 근거로 허용합니다.
- C10~12: 첫 화면 노출을 위한 접기 보완 완료. 1366×768과 1920×1080의 실제 화면 및 scrollWidth/clientWidth 측정 미완료.
- C13: GitHub·Notion 링크 주소 유지. 무로그인 접근과 링크 도착 화면 검증 필요.
- C14~15: 모달 초점 보완, 제목 h1→h2→h3 유지. 실제 키보드 재검증 필요.
- C16: 전체 텍스트·배경 대비율 측정 필요.
- C17: 위 실제 결함 3개의 수정 전후를 제출문에 포함할 수 있음.
- C18: 최종 배포 화면 콘솔 오류 검사 필요. 로컬 문법 검사는 콘솔 검사와 다릅니다.
- C19~22: 펼치기, 모달, 이미지 전환, 애니메이션 정지 및 시스템 동작 줄이기 처리 있음.
- C23: 비공개 선언의 학교·기관 식별 정보/개인 계정과 GitHub 저장소·Notion·학습 이미지 내용의 일치 여부 확인 필요. 군 복무 경험과 건강 정보도 본인이 정한 공개 범위를 확인해야 합니다. 이 검토에서는 사용자가 제공한 본문을 임의 삭제하지 않았습니다.
- C24: 전체 Git 기록·배포 파일·이미지·제출물의 비밀값 검사 미완료. 원문 비밀값을 보고서에 복사하지 마세요.
- C25~26: 아래 제출 초안 제공. 확인하지 않은 결과를 통과로 기재하지 마세요.

## 짧은 확인 방법 4줄

1. 위치: 공개 결과물 첫 화면의 ‘강점과 취향 세 가지’로 갑니다.
2. 행동: ‘학습했던 내용’ 실행 → ‘다음’ 실행 → Esc로 닫습니다. 마우스와 Tab/Enter/Space로 각각 확인합니다.
3. 통과 모습: 모달이 열리고 사진 번호가 01에서 02로 바뀌며 닫은 후 실행 버튼에 초점이 돌아옵니다.
4. 안 될 때 모습: 모달이 열리지 않거나 사진이 깨지거나 번호가 바뀌지 않거나 초점이 배경으로 빠집니다.

## AI와 내 판단 3줄 — 대화 기록 기반 초안

1. AI에게 맡긴 일: HTML/CSS/JavaScript 구현, 디자인 조정, Git 충돌 해결과 과제 기준 대조.
2. 직접 판단한 일: 소개 문구, 실제 경험 내용, 공개 범위와 링크, 공간을 절약하는 배치 방향.
3. AI 제안을 따르지 않은 일: 큰 제목과 장식 라벨, 별도 근거 요약 블록을 삭제하도록 요청했고 배너의 강한 배경도 은은하게 조정하도록 요청함.

제출 전 본인의 판단과 일치하는지 확인하고, 결과물 배포와 고정 소스 커밋 주소를 확정해야 합니다.
